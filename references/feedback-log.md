# 用户反馈 → 规则（两期原话）

## EP01《龙不会老》（2026-11-05）

| 反馈 | 规则 |
|---|---|
| 太纯科普、不感人、没 BGM、角色没动作 | 要情感弧线 + 金句 + 音乐起伏；每个镜头写表演和运镜 |
| 机器人啾啾突兀 | 角色只留老渡、小柚 |
| "为什么叫回声号？" | 开场解释节目名 |
| 字幕不对齐 | 用 whisper 词时间戳 + 拼音对齐 |
| 三次失败重复啰嗦 | 改成蒙太奇 + 年份标签 |
| 连续镜头动作不连贯 | 链式生成，上一条末帧做参考；长台词插听者反应镜头 |
| Puff 歌只在结尾完整放一次 / 中段也要 | 音乐摆放听用户的；歌词让用户提供 |
| 要封面、缩略图、右下角角标；字卡要有背景、字不能抖 | 封面 = 首帧 = attached_pic；字卡静态文字层 + 超采样 zoompan |
| 实拍画面抖 | 高帧率源用 framerate 混帧，不用 vidstab |

## EP02《一诺千年》（2026-11-09～11）

| 反馈 | 规则 |
|---|---|
| 预算 900，省着花；后来"花钱吧不用先问我" | 先估算；授权后可直接补拍，报实际花费 |
| 只有老渡小柚用 AI，其他用影视素材 | 叙述画面全部影视/实拍 |
| 小柚陷进沙发里（务必注意） | POSTURE 锁定、换 plate、QC 检查 |
| 节奏慢、情绪平；但别用加速 | 克隆 2.0 + 语气上下文；老渡沉稳、小柚温柔 |
| 老三国是静态图、推拉在抖；不要 AI 图 | 只用动态原片片段 |
| 小柚/老渡结巴、重复字、卡顿（多次） | 严格 QC + 补拍 + 停顿收紧 + ASR 复核 |
| 声画/口型不同步 | 段音频长度 = 视频；混音 async 重采样 |
| 口型同步（LatentSync）"机器出戏" | 回到 Seedance 原片原声 |
| 采访、百家讲坛、后人片段突兀 | 不插现代原声；旁白 + 镜头 |
| 班洪抗英、佤族房子传说可以 | 扩展内容先出分镜样片给用户看 |
| 致敬结束太快、在字幕位置 | 居中、停留 ≥13 s |
| 没等 BGM 放完就结束 | 片尾音乐倒推对齐，送别完整收尾 |
| 封面哭丧脸难看 | 年轻好看全身像，给 2–3 个候选让用户挑 |
| 成片还是口型版（v9 交错） | 模式切换后检查 concat 来源；不复用旧段 |
| 个别声音卡顿（v10） | tighten.py 收紧停顿 + tverify 复核 |
| 要标题、简介、标签 | 见 publish.md |
