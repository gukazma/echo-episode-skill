# B 站发布文案模板

回复时先写一行"写给：B 站观众"，文案放代码块方便复制。

## 标题（给 3 个，推荐第一个）

反差 + 主题 + 情感钩子，≤ 40 字。EP02 示例：
- 他没借过东风，也没唱过空城计——真实的诸葛亮，守了一句承诺二十七年
- 一诺千年：真实的诸葛亮，比小说里的更了不起
- 47岁还一事无成的刘备，和那个陪他守了二十七年承诺的人

## 简介

```
回声号 第N期｜<片名>

<2–3 句钩子：打破刻板印象 + 主题句>
这一期，老渡和小柚带你回到<时代>，看看<人物>。

【章节】
00:02 冷开场 · ...
mm:ss <段落名>      ← 用 chap.py 从最终 concat 计算，每次重渲后重算
...

【素材与音乐】
影视片段：<剧名/版本>
音乐：<逐一列出>
实拍画面：<地点>等网络公开视频
主持人老渡、小柚的形象与声音由AI生成。
史实以<史料>为主，如有疏漏，欢迎在评论区指正。
```

## 标签（已有话题 + 剩余位）

人物名、相关剧名、经典篇目、主演名（吸引原剧观众）、"历史人物""知识分享"等分类词。EP02：刘备、三国演义、出师表、唐国强、历史人物、知识分享。

## 提醒用户

- 创作声明勾选"含 AI 生成内容"。
- 分区：知识 → 人文历史。
- 上传最新版本号的文件（列出路径，并说明旧版本不要传）。
